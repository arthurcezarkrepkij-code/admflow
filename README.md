# ADMflow

App do administrador da rede CacauFlow, para tablet e celular: faturamento ao vivo, lojas,
pedidos com comprovante, financeiro, alertas e o relatório da IA.

**Protótipo de demonstração, com dados fictícios.**

## Abrir e instalar

Endereço: https://arthurcezarkrepkij-code.github.io/admflow/

- **iPad e iPhone (Safari):** abra o endereço, toque em Compartilhar e em Adicionar à Tela de Início.
- **Android (Chrome):** abra o endereço, menu ⋮ e Instalar app (ou Adicionar à tela inicial).

Abra o app uma vez com internet. Depois disso, ele abre mesmo sem internet.

Login: toque em **Usar o acesso de demonstração** e em **Entrar**.

## Sobre estes arquivos

Esta pasta é o app já compilado (gerado com `npm run build:admflow` no projeto CacauFlow).
Para atualizar, gere o build de novo e substitua os arquivos. O app instalado baixa a versão
nova na próxima vez que abrir com internet.
